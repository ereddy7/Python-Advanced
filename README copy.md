# Python Advanced Material, topic-by-topic programs

Source: Python Advance Material 1.pdf.

This package contains 169 separate `.py` programs in 17 topic folders. Start at folder 01 and run files in numeric order. Every simple code example included in this package has its own file.

## Run
`python 01_OOP_Basics/01_class_docstring.py`

## Important
- Each file is independent unless it is a resource/template example.
- Database examples that require Oracle or MySQL are safe templates because local credentials and servers are not part of the PDF attachment. SQLite examples run immediately.
- Old APIs from the course were modernized, such as `thread.name`, `thread.is_alive()` and `Event.is_set()`.
- Intentionally invalid syntax examples in the PDF are represented safely, rather than placed as non-compiling Python files.
- Programs that ask for keyboard input should be run individually.
