# Python Advanced Programs, grouped from Python Advance Material 1.pdf

Every Python example is in a separate file. Topics: OOP, inheritance, polymorphism, abstraction, exceptions, files/CSV/ZIP/pickle, multithreading, regex, decorators, generators, assertions, logging, and database programming.

Run from the extracted folder, for example: `python 01_oop_basics/002_student_object.py`.

Modernization notes: deprecated threading APIs were updated (`name`, `is_alive`, `daemon`); database credentials are placeholders; SQLite is included as a runnable standard-library database example; network scraping samples were not auto-run; examples that intentionally demonstrate syntax/runtime failures were converted into safe runnable demonstrations where practical.
